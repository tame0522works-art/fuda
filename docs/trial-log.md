# 試用記録

作者が自分のサークルのお品書きを、仮の内容で一から作ってみたときの記録。
操作は作者本人、手順は渡さず「初めて使う人が迷わず進めるか」を見る。

## 2026-10-05 お品書き（仮の内容）

| 詰まったこと | 原因 | 対応 |
|---|---|---|
| 行を増やす方法が分からなかった | 行を増やせるのは「複製」だけで、右パネルの下の方に隠れていた。複製すると斜めにずれて重なるので、行が増えたように見えなかった | 要素を選ぶとすぐ上に「複製・編集・削除」を出す。複製は元の要素のすぐ下に同じ書式で置く。何も選んでいないときの右パネルに案内を出す |
| 画像の入れ方が分かりにくかった。ドラッグで入れたい | 画像は左の「画像」ボタンからファイルを選ぶしかなく、置き場所もページ中央に固定だった | ページへのドラッグ＆ドロップに対応し、落とした位置を中心に置く（ページ内に収める）。複数枚まとめて落としても1手で元に戻せる。ドラッグ中は「ここに画像をドロップ」と出し、「画像」ボタンの下にも案内を添えた。ページの外に落としたときにブラウザが画像を開いてしまうのも防いだ |
| 文字の色を変える場所が分かりにくい | 文字色は右パネルの「テキスト」欄の一番下（文字サイズ・書体・太さ・揃えの後）にあり、画面によってはスクロールしないと見えなかった | 選んだ要素のそばのボタン列に「色」を足した（テキストは文字色、図形は塗り）。右パネルでも文字色を入力欄のすぐ下へ上げた。パレットをドラッグして何度色が変わっても、元に戻す1回で戻る |
| （要望）使えるフォントを増やしたい | 書体はゴシックと明朝の2つだけだった | 丸ゴシック・太い見出し・手書き風・デザイン書体の無料フォント6書体を同梱し、使う文字の分だけ読み込むようにした。Chrome / Edge では PC の書体も一覧に足せる。太字のない書体では太さの切り替えを出さない |
| 初期のお品書きの文字に「枠からはみ出しています」と出る | はみ出しを「行の高さ（行間の余白込み）× 行数」で判定していた。見出し「お品書き」は 96px × 1.4 = 134px で枠の 130px を超える扱いだったが、余白は上下に半分ずつ付くだけで文字は収まっていた（誤検出） | 最後の行の文字の下端（size × (行間 × (行数 − 0.5) + 0.5)）が枠を越えるときだけ警告するようにした。見本の全テキストが枠に収まることを check:doc に加え、値札の長い品名など本当にはみ出す場合は引き続き検出することをブラウザで確認 |
| （要望）PNG で書き出す前にプレビューを見たい | 書き出しボタンを押すと、確認なしにすぐ保存していた | 保存する前に確認画面を出す。表示するのは保存されるファイルそのもの（描き直しではない）で、大きさとファイルサイズも出す。「スマホの画面幅（390px）」に切り替えて、SNS で文字が読めるかを確かめられる。「保存する」は確認した画像をそのまま保存する。確認画面の間は裏のページのショートカットを止める |

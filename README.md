# fuda

即売会のお品書き・机上ポップ・値札を、ブラウザの中だけで作るエディタ。

**アプリ:** https://tame0522works-art.github.io/fuda/ （インストール不要。PC のブラウザ向け）

- **お品書き** … SNS に載せる PNG 画像（1080×1350 など）
- **ポップ** … 机に立てる印刷用 PDF（A4 / B5 / A5 / B6）
- **値札** … 1枚デザインして品目を差し込み、A4 に面付けした PDF（名刺サイズなら10面）

デザインも表紙画像も端末の IndexedDB にだけ保存し、どこにも送りません。

## 作りの要点

### 3種類の出力を1つのエンジンで描く

お品書き・ポップ・値札は、どれも「1枚のページに要素を自由に置いたもの」として扱います。
違うのは用紙の単位（画像は px、印刷物は mm）と書き出し方だけです。
画面表示・PNG・PDF・面付けは、すべて [`drawDoc`](src/render.ts) という1つの描画関数を通ります。

### 画面と書き出しで改行位置をずらさない

文字の折り返しは描く倍率に関係なく、常に 100px 基準で測ります。
画面（小さく描く）と 300dpi の書き出し（大きく描く）ではフォントのヒンティングで幅が微妙に変わり、
倍率ごとに測ると「画面では1行だったのに印刷すると2行になる」が起きるためです。
折り返しは日本語の禁則（句読点のぶら下げ・開き括弧の追い出し）を守り、`1200円` や `Vol2` のような英数字の並びは途中で折りません。

### 整列ガイド

ドラッグ中の要素を、ページの端・中央と、他の要素の端・中央に吸着させ、揃った線をガイドとして表示します。
拡大縮小ではつまんだ辺だけを吸着させ、反対側の辺は動かしません。
吸着する距離は用紙の単位ではなく画面上の 6px で決めています（mm の値札を拡大表示していても、px のお品書きでも同じ手触りにするため）。
Alt を押している間は吸着しません。

### 画面上で直接書き換える

テキストをダブルクリック（または選んで Enter）すると、キャンバスの文字の真上に同じ位置・大きさ・書体の入力欄を重ねます。
Esc・Ctrl+Enter・外側のクリックで確定し、何文字打っても「元に戻す」1回で入力前に戻ります。
中身を空にして確定するとテキストごと消えます（これも元に戻せます）。

### 値札は品目ごとに「はみ出し」を検出する

値札は品名の長さが品目ごとに違うので、テンプレートが1つでも一部の品目だけ文字が枠からはみ出します。
品目一覧で、はみ出す品目に印を付けます。

### PDF はライブラリを使わず自前で組む

必要なのは「1ページに1枚の画像を全面に貼った PDF」だけなので、仕様の最小限（約100行）を自前で書いています。
画像は JPEG ではなく可逆圧縮（FlateDecode。ブラウザ標準の `CompressionStream` を使用）で埋め込み、文字の輪郭ににじみを出しません。

### tsuri と品目を共有する

[tsuri](https://github.com/tame0522works-art/tsuri)（即売会の頒布管理）の「バックアップ（JSON）」を読み込むと、品名と価格が値札の品目になります。

## 書き出しの実測

2026-10-05、AMD Ryzen 7 5700X ／ Chrome 152（Claude デスクトップアプリの内蔵ブラウザ）、開発サーバー上で計測。
初期表示の見本デザイン（文字と図形のみ、画像なし）を使い、各条件で1回空打ちしたあと5回測った中央値（カッコ内は最小〜最大）。

| 対象 | 出力 | 時間 | サイズ |
|---|---|---|---|
| お品書き | PNG 1080×1350 | 16 ms（12〜23） | 104 KB |
| ポップ A4 | PDF 300dpi 1ページ | 182 ms（180〜191） | 85 KB |
| ポップ A5 | PDF 300dpi 1ページ | 99 ms（96〜103） | 57 KB |
| 値札 名刺サイズ 10品目 | PDF A4 1枚 | 207 ms（195〜211） | 197 KB |
| 値札 名刺サイズ 50品目 | PDF A4 5枚 | 938 ms（909〜1014） | 966 KB |

- **値札は A4 1枚あたり約 0.2 秒・約 200 KB で、枚数にほぼ比例する。** 50品目（5枚）でも1秒以内に収まる。
- **可逆圧縮にしてもサイズは増えなかった。** 同じポップ A4 を JPEG（品質0.92）にすると 139 KB で、可逆圧縮の 85 KB より大きい。べた塗りの多いページでは可逆圧縮がよく効くため、文字のにじみを避けてもサイズの代償はない。
- **書き出し中は画面が止まる。** 描画はメインスレッドで行っている。いちばん重い50品目でも1秒弱なので、今は Worker に移していない。
- **まだ測っていないこと:** 写真を全面に敷いたポップ。写真は可逆圧縮が効きにくいので、上の表より大幅に大きくなる見込み。

測り直すときは `npm run dev` で開発サーバーを起動し、`/bench.html` を開いて「計測する」を押す（このページは本番ビルドに含めない）。
表紙画像を選んでから測ると、写真を全面に敷いたポップの時間とサイズも出る。
